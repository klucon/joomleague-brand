# JoomLeague Integration Examples

This folder contains copy-ready examples showing exactly how to use FINAL v8 assets.

## Folders

- `joomla/`
  Joomla administration/menu usage and extension media mapping.

- `html/`
  Standard HTML `<head>` integration for favicon, Apple, PWA, Safari and Windows metadata.

- `pwa/`
  PWA manifest and service-worker examples.

- `windows/`
  Windows tile configuration and desktop ICO guidance.

- `linux/`
  Linux `.desktop` example and hicolor icon installation paths.

- `github/`
  GitHub README branding and social-preview mapping.

## Codex selection order

Before choosing an asset:

1. Read `developer/ai/assets.json`.
2. Read `developer/ai/ASSET_USAGE.md`.
3. Use the closest integration example in this folder.
4. Prefer simplified SVG icons for small UI.
5. Prefer the full glossy emblem only at larger display sizes.
6. Never introduce sport-specific imagery.

## Important

These files are examples. Paths assume the FINAL v8 directory structure remains intact.
Adjust the URL prefix only when deploying the assets to another public path.
