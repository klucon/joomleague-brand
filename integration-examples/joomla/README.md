# Joomla integration

Recommended assets:
- Joomla menu / toolbar icon:
  `developer/svg/joomleague-symbol-currentcolor.svg`
- Light background symbol:
  `developer/svg/joomleague-symbol-blue.svg`
- Dark background symbol:
  `developer/svg/joomleague-symbol-white.svg`
- Full logo:
  `logos/joomleague-logo-standard-transparent.png`

For small administration UI elements, prefer the simplified SVG symbols rather than the glossy raster emblem.
