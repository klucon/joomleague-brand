# Windows usage

For a web tile:
- `favicons/browserconfig.xml`
- `favicons/mstile-70x70.png`
- `favicons/mstile-150x150.png`
- `favicons/mstile-310x150.png`
- `favicons/mstile-310x310.png`

For a Windows desktop application:
- `developer/windows/joomleague-app-icon.ico`

The ICO contains 16, 24, 32, 48, 64, 128 and 256 px sizes.
