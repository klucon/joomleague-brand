# Codex integration rules

When implementing JoomLeague branding:

- Browser tab:
  use `favicons/favicon.svg`, with `favicons/favicon.ico` as fallback.

- Joomla admin menu:
  use `developer/svg/joomleague-symbol-currentcolor.svg`.

- Small toolbar icon:
  use `developer/svg/joomleague-symbol-outline.svg`.

- Apple:
  use `favicons/apple-touch-icon.png`.

- Android / PWA:
  use the manifest plus the maskable 512 icon.

- Windows desktop:
  use `developer/windows/joomleague-app-icon.ico`.

- Linux desktop:
  use the hicolor PNG matching the target size.

- GitHub:
  use the GitHub banner for README presentation and the 1200×630 social image for repository social preview.

Never crop the wordmark to manufacture an icon.
Never add imagery from any specific sport.
