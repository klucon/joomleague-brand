# JoomLeague Pantone reference

These are approximate candidate matches for the approved digital brand colors.

| Brand color | HEX | Approximate Pantone candidate |
|---|---|---|
| Blue | #0062A9 | PANTONE 307 C |
| Green | #46B450 | PANTONE 361 C |
| Orange | #F39C12 | PANTONE 1375 C |
| Red | #E74C3C | PANTONE 7417 C |

These values are not contractual spot-color specifications.

Before a spot-color print run:
1. compare the approved digital color with a current physical Pantone guide;
2. request a printer proof;
3. lock the selected ink specification with the print supplier.
