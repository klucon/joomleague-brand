# JoomLeague Design Tokens

Canonical brand colors:

- Blue `#0062A9`
- Green `#46B450`
- Orange `#F39C12`
- Red `#E74C3C`

Files:

- `joomleague-tokens.css` - CSS custom properties
- `_joomleague-tokens.scss` - Sass variables and helpers
- `joomleague-tokens.json` - machine-readable design tokens

## Important

The JoomLeague wordmark is artwork. Do not recreate the logo by styling normal text.

For ordinary UI typography, the pack recommends an Inter/system-sans stack. This is an
interface recommendation, not a replacement for the wordmark artwork.

JoomLeague is sport-neutral. Design tokens must never be combined with sport-specific
branding assumptions.
