# Figma import package

Native `.fig` project files are proprietary and are not generated by this pack.

Import these files into Figma:
- `joomleague-symbol-flat.svg` - preferred editable vector symbol
- `joomleague-symbol-outline.svg` - small/UI vector
- `joomleague-symbol-currentcolor.svg` - developer-oriented vector source
- `joomleague-logo-highres.png` - approved glossy logo artwork

Use `figma-color-styles.json` to create local color styles.

Important:
The approved glossy full logo is raster artwork. Do not redraw or approximate the wordmark in Figma.
Use the vector symbol for fully editable vector applications.
