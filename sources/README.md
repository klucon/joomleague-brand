# JoomLeague source files

This folder contains open/importable master sources.

## Figma
Use `sources/figma/`.
The SVG files import as editable vectors. The approved full glossy logo is supplied as high-resolution PNG.

## Adobe
Use `sources/adobe/`.
SVG, EPS and PDF are Illustrator-compatible vector interchange formats.

## Master
Use `sources/master/` for canonical source artwork.

## Native-format note
Figma `.fig` and Adobe Illustrator `.ai` are proprietary native project formats.
This pack intentionally provides open, durable interchange sources instead of fake or invalid native files.
