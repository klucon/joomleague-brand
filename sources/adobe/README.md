# Adobe source package

Native Adobe Illustrator `.ai` files are proprietary and are not synthesized here.

Use:
- SVG for editable vector work in Illustrator
- EPS for legacy/vector print workflows
- PDF for interchange and prepress
- `joomleague-logo-approved-raster.png` for the approved glossy full logo

The simplified symbol is the true editable vector source supplied by this pack.
The glossy wordmark/logo remains approved raster artwork and should not be reconstructed from normal text.
