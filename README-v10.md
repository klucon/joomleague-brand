# JoomLeague Brand Ecosystem FINAL v10

This package expands the FINAL v9 brand kit into a complete brand ecosystem for
web, Joomla, documentation, print, community, marketplace, releases, developer tooling,
AI/Codex usage and CI validation.

## What is new in v10

- Dark mode asset pack
- High-contrast accessibility pack
- Monochrome, embroidery, laser/CNC/vinyl and signage production packs
- Print bleed templates
- Press kit and media kit
- Social media, YouTube, Discord/forum packs
- Joomla marketplace assets
- Release artwork templates
- Version badges and status badges
- Documentation headers
- Presentation template
- DOCX document template
- Email signature and newsletter headers
- CSS component kit
- Bootstrap 5 theme variables
- Joomla admin tokens
- Web Component icon
- SVG sprite
- Icon-font source mapping
- npm package scaffold
- Composer package scaffold
- Codex auto-selector CLI
- Expanded English and Czech brand manuals

## Important rule

JoomLeague is sport-neutral. Do not add sport-specific imagery into core branding.
