=======================================================

   - favicon.ico

   - mstile-310x310.png
   - browserconfig.xml

5. Safari pinned tab:
   - safari-pinned-tab.svg

Recommended production usage
----------------------------
- Use favicon.svg as the modern browser favicon.
- Keep favicon.ico as a fallback for legacy browsers.
- Use apple-touch-icon.png for iPhone/iPad home screen icons.
- Use site.webmanifest for Android and PWA support.
- Use browserconfig.xml for Windows tile support.
- Use safari-pinned-tab.svg for Safari pinned tabs.

Notes
-----
- All icons use the clean standalone JoomLeague emblem only.
- No wordmark text is included in mobile or favicon assets.
- Apple icons use a white opaque background.
- Standard Android icons use transparent background.
- Maskable Android icons use Joomla blue background for safer adaptive cropping.
